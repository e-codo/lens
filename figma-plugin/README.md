# Плагин Figma: Lens distortion

Берёт выделенный слой или фрейм, применяет эффект дисторсии объектива и создаёт новый слой с картинкой рядом с оригиналом. Оригинал не меняется.

## Установка

Нужно десктопное приложение Figma. Сборка не требуется.

1. Склонируйте репозиторий или скачайте папку `figma-plugin`.
2. В Figma откройте любой файл.
3. Меню: Plugins → Development → Import plugin from manifest…
4. Выберите файл `figma-plugin/manifest.json`.
5. Запуск: Plugins → Development → Lens distortion.

## Использование

1. Выделите один слой или фрейм.
2. Настройте эффект в окне плагина: искажение, аберрация, масштаб (кнопка «Авто» убирает растянутые края), радиус, центр, режим, качество.
3. Нажмите «Создать слой рядом». Справа от оригинала появится прямоугольник с обработанным изображением.

Кнопка «Оригинал» при удержании показывает исходную картинку.

## Ограничения

- Это не живой эффект. После создания слоя искажение нельзя подкрутить. Чтобы изменить, запустите плагин заново на оригинале.
- Для обработки слой экспортируется с масштабом до 2x, но не больше 4096 px по большей стороне.
- Выделять нужно один слой за раз.
